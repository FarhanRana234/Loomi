# Loomi 🚀

Loomi is a visual social platform that blends Pinterest-style content discovery with Instagram-like community interaction. Users can upload photography, videos, and media, organize content into moodboards, and engage with posts in a fluid, responsive feed.

🔗 **Live Demo:** [loomi-ashen.vercel.app](https://loomi-ashen.vercel.app/)

---

## ✨ Features

- **Visual Feed:** Responsive masonry grid with support for light and dark modes.
- **Authentication:** Secure user authentication using Firebase Auth (Google Sign-In).
- **Media Uploads:** Dynamic image and video hosting via Cloudinary.
- **Social Interaction:** Likes, saves, custom moodboards, user profiles, and audio tagging.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Database:** [MongoDB](https://www.mongodb.com/)
- **Authentication:** [Firebase Auth](https://firebase.google.com/)
- **Media Management:** [Cloudinary](https://cloudinary.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/FarhanRana234/Loomi.git](https://github.com/FarhanRana234/Loomi.git)
   cd Loomi
   
2. Install dependencies:
   npm install
    # or
   yarn install
    # or
   pnpm install
   
3. Set up environment variables:
   Copy .env.example to .env.local and fill in your own credentials (MongoDB connection string, Firebase keys, Cloudinary API credentials):
   cp .env.example .env.local

5. Run the development server:
   npm run dev
   Open http://localhost:3000 with your browser to see the app in action.
